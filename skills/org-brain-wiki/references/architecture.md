# Architecture

Search existing entity and architecture pages before creating a page. Inspect
the current implementation or an explicitly selected specification; distinguish
implemented behavior from approved plans and inferred intent.

Record the component's responsibility, storage ownership, inputs/outputs,
concurrency rules and failure behavior. Cite the source version and verified
range for each important contract. Keep measured performance separate from
complexity analysis, with device, revision, corpus and timing boundaries.

Link existing components by stable page IDs. Update affected contracts when a
source changes; do not rewrite unrelated pages or treat a stale diagram as proof.
Propose semantic inconsistencies for agent review rather than declaring them
automatically resolved.
