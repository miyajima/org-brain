# Procedure

Search for an existing procedure and related system pages. Ground steps in an
examined runbook or a verified execution. Record prerequisites, target selection,
inputs, commands, expected outputs, verification and recovery steps.

Separate a dry run, local test and production acceptance. Include environment
and version constraints needed to reproduce the result. Never preserve tokens,
credentials, transcripts or private records as example inputs. Unverified steps
must be labeled as such, not promoted to a tested operating procedure.

Keep operations involving publication, remote changes, deletion, payments or
credentials subject to their existing approval requirements. Saving a procedure
does not authorize executing it. Cite actual source versions and verified ranges,
then run structural diagnostics after updating the page.
