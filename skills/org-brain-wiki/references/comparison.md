# Comparison

Search for the existing comparison and its entity pages. Define the decision
question and criteria before collecting evidence. Use examined primary sources;
record the retrieval date or inspected revision for facts that may change.

Compare the same scope and conditions. Separate source claims, observed behavior,
measurements and recommendations. Mark unavailable evidence explicitly; do not
replace missing measurements with estimates presented as results. Preserve older
measurements with their original conditions rather than silently overwriting them.

Keep a single comparison page for the reusable question and link existing entity
pages. Create another entity page only when it has independently reusable facts.
An approved product decision remains authoritative in OrgBrain memory; reference
it rather than converting an agent recommendation into a confirmed decision.
