# OrgBrain Console UX 現状評価

- 監査日: 2026-08-17
- 対象: `apps/console`
- 言語: 日本語 (`lang=ja`)
- 画面幅: デスクトップ 1280 x 720、モバイル 390 x 844
- データ: ローカル E2E モック API
- 総合評価: **54 / 100 (C-)**

## 画面・フロー別評価

1. 組織の活動 — **58 / 100、要改善**。期間切替とデータ鮮度は明確だが、ユーザーが要対応事項を把握する前に中央の可視化が主役になる。
2. 管理ナビゲーション — **42 / 100、不良**。デスクトップは12項目がフラットに並び、モバイルでは「グループ・ユーザー・組織・業務カテゴリ・プロフィール」が欠落する。
3. 知識のつながり — **50 / 100、要改善**。判断の4段階モデルは良いが、ラベルのない3Dノードと折りたたまれたノード選択UIが開始操作を隠している。
4. 判断詳細 — **56 / 100、要改善**。決定・理由・根拠・成果物の順序は強いが、利用可能な代替データと同時に技術的なGETエラーが露出する。
5. 知識の履歴 — **68 / 100、まずまず**。「今日の変更をレビュー」と「いま見るべきこと」は行動の優先順位を作る一方、対象範囲と取得元の説明が最初の画面を圧迫する。
6. Task監視 — **38 / 100、不良**。一覧は簡潔だが、失敗Taskを開くと「Taskが見つかりません」「イベントなし」で行き止まりになり、回復操作がない。
7. 運用ステータス — **76 / 100、良好**。重要度・件数・説明・行動リンクが揃い、次に何をすべきかが明確。再利用すべき最良パターン。
8. ユーザー管理 — **43 / 100、不良**。日本語指定でも英語になり、招待と編集に明確なセクション名がなく、ロール・状態も実装用語のまま。
9. モバイル — **49 / 100、不良**。横スクロールなしで本文は再配置されるが、ナビゲーションの機能差と説明文の密度が操作を押し下げる。

## 影響の大きい問題

1. **ナビゲーションの機能差**：モバイルではデスクトップにある5つの管理領域へ到達できない。
2. **ローカライズ不足**：`lang=ja` でも Users 画面とグローバルナビが英語になる。
3. **失敗時の回復手段不足**：失敗Taskから「見つからない／イベントなし」に遷移し、戻る・再実行・更新・説明がない。
4. **トップが行動優先ではなく観察優先**：要対応事項より、読み解きに時間がかかるトポロジーが視覚的に優先される。
5. **3Dマップが分かりやすい入口を隠す**：検索できるノード一覧がグラフ下部で折りたたまれている。
6. **可読性が不安定**：フォームラベルは約11.84pxかつ低い不透明度・広い字間で、タイムラインにはさらに小さい文字がある。

## 維持すべき強み

- フォーカス表示があり、見出し・ランドマーク・表・ラベルの多くは意味的に実装されている。
- 操作対象は概ね高さ44pxを満たす。
- 「データが古い」と最終更新時刻が明示されている。
- 判断の4段階トレースは強い情報モデルになっている。
- 運用ステータスは、現行デザインでも行動優先の明確な画面を作れることを示している。

## 改善順序

1. ナビゲーションの機能差、言語引き継ぎ、壊れたTask詳細の回復導線を直す。
2. 活動画面を「要対応・健全性・直近の変化」中心に再構成し、トポロジーは分析用へ下げる。
3. 知識のつながりはノード一覧・検索を標準の入口にし、3Dは任意の可視化にする。
4. ページテンプレート、見出し、行動ラベル、空・エラー状態、文字サイズ、コントラストを統一する。

## 確認範囲の限界

- ローカルのモックデータを使ったスクリーンショット・操作監査であり、本番テレメトリ調査ではない。
- キーボードフォーカスの表示とDOMの意味構造は確認したが、スクリーンリーダー・ズーム・色コントラスト・自動WCAG監査は未実施。
- Invite、Save、再実行など状態変更を伴う操作は送信していない。
