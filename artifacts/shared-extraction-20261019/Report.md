# OrgBrain 共通再抽出と本文保持の比較

2026-10-19、ローカル実装と実モデル比較。共通経路は Claude/Cursor/Codex の Stop → 非公開ローカルキュー → APIワーカー。Codex CLIへの依存を外した。通常経路の入力選択、空候補の受理、検証報告の保存、保存時の本文変化を修正した。

## 実装

モデルは `anthropic/claude-sonnet-5.5` / low。既存のOpenRouter設定を再利用した。初回のAnthropic直接提供先指定はZDR対応の提供先がなくHTTP404だったため、公開のZDR提供先一覧を確認し、同じモデルの `google-vertex/global` に明示変更した。フォールバックや別モデルへの切り替えはしていない。

理由や例外がある入力をルーターの一部の支援IDだけに狭めず、全文から関連文のまとまりを作る。入力上限に収まらないまとまりは切らずに保留する。モデルには文番号を選ばせ、検証器で本文に戻す。空の候補は拒否する一方、空の任意項目で他の有効な候補まで失わない。

検証報告は `reported_verification: {state: unverified, text: ...}` として本文に保存する。同一の成功ツール呼び出しがない報告を実行証明に昇格させない。保存時の伏字処理で意味のある本文が変わる候補も保留にする。候補は quarantine に保存し、自動昇格を無効にした。

既存 v1.1 / v1.2 ランナーは宣言・要求検証・実際の生成CLI引数を `gpt-6.1-sol` / low に統一した。以前の実験ファイル・実行履歴は変更していない。古い「凍結済み検証器」という参照は現在の共有検証器への明示的な参照に改め、依存ファイルを実行マニフェストに含めた。

## 比較方法

過去に指定された9プロジェクトの固定原資料を再利用した。443記憶そのものを正解として与えず、その由来の実入力100ケースと完了ターン18ケース、合計118ケースを使用した。AImaは原資料がなく未取得。

変更前は修正直前に保存した通常のルーター・v2入力選択・検証器、変更後は共通キューの通常処理。元の資料は同一で、提示量の変更も改善対象に含む。両側のモデル・effort・提供先・入力上限2000・出力上限800は同じ。通常の耐久性判定と秘密情報の除外を迂回していない。

API呼び出しは変更前51回、変更後150回。変更後は関連文を分割して扱うため、1ケース1回とは限らない。費用や呼び出し数が同一の比較ではなく、経路全体の動作比較である。品質の経済的優位は主張しない。

実応答で任意項目の `refs=[]` がある4ジョブを過剰に保留する問題が判明した。パーサー修正後、保存済みの全150応答を同じ入力と共有検証器で再検証し、通常の保存関数で別の非公開DBに保存・読み戻した。モデルへの再送は0回。レビュー後の最終入力も150パケットすべてで元の実行時とプロンプトが一致し、最終の共通キュー・通常ワーカーへ保存済み実応答を再適用した。90候補の保存本文が再検証結果と一致し、追加API呼び出しは0回。出力打ち切り1回は受理せず、再試行していない。

## 結果

本文を持つ保存候補は **変更前0件 → 変更後90件**。90件すべてで、検証後の意味のある本文と保存後の本文が一致した。active記憶の作成・既存記憶の書き換えは行っていない。

速報では65件と数えたが、保存時にIDが伏字になり、ケース別の読み取りが漏れていた。初回DBの実件数は88件だった。生成IDの扱いと任意の空項目を直し、本文が変わる2候補を保留した後の最終読み戻し件数が90件。65件は最終値として使用しない。

表は原資料の文から語句で判定した参考指標。本文の意味を人手で採点した保持率ではない。分母には、耐久性判定で抽出対象にならなかった発言も含む。秘密・安全規則で原資料全体が除外されたケースはこの分母に含めない。原資料へのリンク・ID・出典だけの残存は分子に数えない。

全体では理由4/20文、例外・条件62/207文、検証関連51/215文が保存後の意味のある本文に残った。モデル提示段階では、それぞれ2→6文、12→85文、27→88文に増えた。**全原資料の完全な保持は達成していない。** 特にSFK等では通常の耐久性判定で対象外になる資料が多く、出力でも抽出されない内容がある。

`reported_verification` 専用項目は2候補。consentsideとjrgで、理由・再利用条件・未検証の検証報告が同じ成功候補の本文に残り、保存後にも一致した。`observed_outcome` / `verified_outcome` の受理は0件。したがって、自己申告を保存できたことを、実行証明を保存できたこととは扱わない。

入力上限で6まとまりを保留、出力打ち切りで1応答を不受理、保存時に本文が変化する2候補を保留した。保留を正常な抽出成功に数えず、自動再送しない。

比較APIの判明費用は0.534204ドル、成功した接続確認を含む判明費用は0.536108ドル。最初のHTTP404試行の課金値は取得できていない。上限5ドルの範囲内で実施した。価格・API応答の値であり、アカウントの請求額の照合ではない。
