# Stop後の自動抽出・保存の実動作確認

2026-10-19（Asia/Tokyo）。Claude/Cursorの通常Stop後に、手動の抽出コマンドなしで共有ワーカーを起動する変更。両クライアントの実セッションで通常Stopからの自動抽出・保存を確認した。Cursorでは利用者の送信操作補助を含み、無人で画面入力まで完結した試験ではない。

## 導入した動作

既存の非公開hooks.envに `ORGBRAIN_SESSION_EXTRACTION_AUTORUN=true` を追加し、確認済みバンドルを既存ランタイムへ反映した。原本バックアップとバイト照合を行い、認証・モデル・保存先・他の設定は保持した。新しいスケジュールや常駐サービスは追加していない。

Stopは通常の入力選択・安全判定・キュー投入後に、同じNodeと導入済みCLIの別プロセスを起動する。フック内でモデルを呼ばず、API終了も待たない。モードon・対象allowlist・有効なローカルフックが前提。confirmモード・除外セッション・対象外は起動しない。明示設定にAUTORUNが無い場合は親の値で有効化しない。

ワーカーはキュー/テナント/プロジェクト単位で排他し、手動・autonomyにも同じ制御を適用する。1プロセス20ジョブまで。終了時に未処理確認と排他解除を同じトランザクションで行い、残りがあれば別プロセスへ引き継ぐ。重複Stopも未処理があれば起動を試す。生存時間だけで所有者を追い出さず、OSの起動識別情報でPID再利用を区別する。識別できない環境では停止し、排他を弱めない。異常終了したrunningやheldは再送しない。API失敗・予算切れ・例外時は連続起動しない。

## Claude Codeでの実測

通常のOrgBrainワークスペースでClaude Codeの実セッションを1回実行。Sonnet/low・クライアント上限1ドル・Nodeあり/CodexなしPATH・MCP/子エージェント/編集なし。既存運用文書の3項目をPythonで読み取り確認し、失敗優先の継続手順、理由、例外、文書検査結果と未検証の範囲を回答させた。合成Stopや手動キュー再投入は行っていない。

- 通常OrgBrain Stopはstatus 0、237msで終了。
- 自動起動された別ワーカーが6ジョブを完了、5候補を通常保存先へ保存。失敗0。ワーカー開始から終了まで約9.9秒。
- 6応答ともモデルID anthropic/claude-sonnet-5.5、提供先Google。要求effortはlow。抽出API費用は0.015424ドル。クライアント生成費用の報告0.0654462ドルとは別。
- 実セッションの正規安全処理後の38入力文と、キューの全38文が一致。
- 5候補はquarantine・自動昇格禁止。少なくとも1候補で理由・例外・文書検査結果の報告が同じ本文に残った。全候補が全項目を含むわけではなく、5件を独立した知識5件と数えない。reported_verification専用欄や独立したツール成功のoutcomeは今回生成されていない。
- 保存済み応答を共有検証器へ再適用し、JSONのキー順と保存されないundefined項目を除いて比較した意味本文が5件とも保存本文と一致。追加API呼び出し0。
- 既存3候補と既存6ジョブは全列不変。

## Cursorでの実測

前回のOrgBrain policy check verificationチャットに、利用者が検証依頼を1回送信した。画面でSonnet 5.5 Low / This Mac、実行した文書検査の3項目成功・終了コード0、依頼B20261019に対応する最終回答を確認した。入力操作補助を含むが、抽出コマンドや合成Stopは実行していない。

- 通常Stopのキュー投入直後に自動ワーカーが起動し、3ジョブ完了・2候補保存・失敗0。ワーカー開始から終了まで5.230秒。
- 3応答ともモデルID anthropic/claude-sonnet-5.5、提供先Google。要求effortはlow。抽出API費用は0.006728ドル。Cursorクライアント自体の利用料は別で、この記録では未集計。
- 当該実セッションの最終完了ターンを通常アダプターで選択し、正規安全処理後の全17入力文と、キューの全17文が一致した。対象外クライアントや別セッションは今回の集計に混ぜていない。
- 保存した2候補は、どちらも同じ本文に理由・例外・文書3項目成功の報告を含む。最終共有検証器へ保存済み応答を再適用し、2件とも保存本文と意味JSONが一致。追加モデル呼出し0。
- 2候補ともquarantine・自動昇格禁止。reported_verification専用欄や独立したツール成功のoutcomeは今回生成されていない。検証報告が本文に残ったことと、独立した実行証明を保持したことを区別する。

## 回帰検証と限界

修正前の失敗を確認してから実装した。関連28テストと既存フック46テスト成功。配布バンドルの実プロセス起動・保存テストも成功（APIはテスト用応答）。CLI互換性を保つようヘルプ変更を追記形式へ修正した。独立レビューで、busy時の集計による上限超過、PID再利用、不明費用の0扱いを修正し、再レビューpass。

実動作の結果はこのMacに限る。Linux/Windows、制約付きサンドボックス、スリープ/再起動中の即時処理や全タスクでの情報保持率は未検証。レビューの要求モデル名は実ホストのモデル証明として扱っていない。確定記憶への昇格はこの作業に含まない。

通常設定と停止方法は [SESSION_EXTRACTION.md](../../docs/SESSION_EXTRACTION.md)。`orgbrain memory extraction status --project-id org-brain --worker` で実行状態と処理・保存件数を確認できる。起動済みと保存完了は区別する。
