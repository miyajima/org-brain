# 過剰拒否修正と初回費の回収回数

今回の追加予算10 USD、最大120 CLI開始、累計616回。過去496回・16.9021869 USDとは別枠。初段は初回成果3件＋3種類×6回×2条件の39開始、API換算見積約2.8 USD。失敗・修正・再実行・初回作成を含める。次の開始に0.30 USDの余裕を確保し、各CLIの上限は0.25 USD。欠測費用があれば停止する。実請求・親の実装監査費・人件費は未取得。

実モデルclaude-sonnet-5-5、effort medium。ログで照合する。固定応答の再生は機能試験のみ。調査・分析・文書作成の同じ原資料と要求3単位を用い、対照は全3単位を生成、差分は新1単位を生成して初回成果の2単位を保持する。初回成果は今回の実装で3件新規作成し、全額を累計へ一度だけ加える。各試行は別セッション・隔離DBで同じ初回成果を参照し、過去の差分出力を次の入力へ流用しない。人の分岐選択のみ模擬。原資料・コード・課題は最初のモデル開始前に固定し、順序を交互にする。

1～6回再利用時点の初回費込み累計トークン・機械時間・API換算費用を、同じ回数の記憶なしと比較する。全3種類の合計と種類別を分ける。単なる推定回収回数にせず、実際の各再利用の使用量を累積する。初回費を除く値も別掲する。全トークンは入力・cache作成・cache読込・出力の合計。ホスト準備＋CLI実時間に検索・注入・検査・追跡・修正を含め、重複加算しない。評価専用コピーと親の作業は別勘定。

最初の6回までは結果で打ち切らない。その後、両指標が初めて減少した回数と、その後2回でも減少を維持したかを確認する。未達なら各種類1回ずつ（6モデル開始）のまとまりで追加し、同じ版では最大18回再利用まで。合計だけでなく各種類を確認する。品質失敗・予算到達・欠測は保持して停止し、修正が必要なら同一原資料・版の比較を混ぜない。結果を見て打ち切るため、交差点はこの固定課題での記述値であり、一般的な統計的保証とはしない。

引用位置・原本ID/版/ハッシュ・権限・期限・実操作・完成ファイルの独立コード監査を維持。各追加節と結合後の必須事実、対照の数値・分母・設定・未観測事項を確認する。検査に通っただけで意味の品質や有用性を認定しない。旧節不変とホストによる成果再利用を、モデルの原本読取へ置き換えない。試験DB・成果を通常DBへ取り込まない。

人の新版の採否・注意時間は実回答が無ければ欠測。旧版の初回確認実測を転用しない。推定は純増人時間を1回10/30/60秒と仮定した感度分析とし、採否・初回人確認の配分・両条件の最終確認/修正の差を含む。機械時間と人を含む時間を混同しない。クラウド展開なし。

実施中の補足: 最初の回の全文確認で対照1件・差分1件に未支持の断定を検出した。該当ケースの品質認定を止め、独立した他ケースの固定比較は継続する。未支持の原出力を保持し、同じ資料・版・依頼文で再作成する。comparison-repair-*として新しい開始を記録し、失敗した生成も含めた全費用を元ケースへ加える。再作成のための親の確認時間は未測定で、機械の削減を人の削減へ置き換えない。
