# 全体実施の費用分解と改善比較

2026-10-31。承認済み上限は追加24 CLI開始・累計461、API換算3.60 USD。見積約2.80 USD。初回成果3、比較18、準備・失敗の予備3を含む。実請求額、親の実装・監査費用は別勘定で未取得。クラウド展開なし。

調査・分析・文書作成について各2課題を固定し、記憶なし／現行の全体実施／改善版の全体実施を各6回比較する。各課題で順序を回転する。原資料はこのプロジェクトの実ファイルで、モデルはclaude-sonnet-5-5、effortはmedium。CLIの実版と実モデルをログで確認する。初回成果も同じ最終実装・原資料で実モデルにより作成する。各比較は同じ初回DBのコピーを使い、他の条件で生成した成果を候補へ混入させない。

記憶なしと改善版は、JSON本文を引用済みheredocの標準入力で渡す方式と短い完了証跡を共通にする。現行は従来のJSONシェル引数と本文を含む応答。記憶あり2条件はモデル起動前に既存成果を探し、全体実施を選択する。選択は評価用に固定し、実際の人の採用判断として扱わない。改善版でも選択前の原本・版・権限・期限・成果の照合は維持する。選択後の全体実施は現在の資料を全単位読み、旧成果を適用しないため、旧成果の再検査を省く。差分・既存完了の照合は省かない。

新しい標準入力経路はファイル原本で記憶参照IDがない対象だけに限定する。ホストがタスク・利用者・単位・操作を決め、実際のネイティブBash入力、標準入力全文、実アダプター出力と完成ファイルを照合する。短いツール応答の裏に全文の実出力とハッシュを保持し、元の記憶を読んだという記録に置き換えない。元の記憶参照がある操作の利用報告は従来の厳格な検査を維持する。

計測用の設定・DBは明示test設定と専用環境変数がそろう場合だけ読み込む。通常のDB・設定は比較中に切り替えない。各フックを入出力を変えない時間計測器で囲み、工程別時間を保存する。モデルの操作内部では検証とアダプター実行の時間を別記する。フックの時間、プロセス準備、CLI総時間、API時間と残差を混同しない。計測器自体の起動負荷はCLI総時間へ含まれる。設定複製などの評価専用準備と、通常の確認・資料準備を分ける。

全4トークン区分をmodelUsageの実測から集計する。ターン別出力に欠測がある場合、0で補わず未配賦のまま残す。拒否された操作、未完了CLI、再実行の時間・費用を保存し、最終成功だけで集計しない。固定モデル応答の再生は使わない。時間計測中にテスト・ビルド・Wiki整備を並行しない。

必須条件は、同じ対象の全単位、値・分母・単位・適用条件と未観測事項の保持、実引数と実ファイルの一致、無権限・対象外・改ざん・再送の拒否である。各条件の結果は別のPythonコードで照合し、親が原資料と完成内容を確認する。改善版の失敗を隠さず、未達なら通常利用のフラグは有効にしない。
