# Design Intent

## Goal

Help any Org Brain member understand when to use each insight screen, what it shows, and which source-of-truth action to take next without removing the existing sense of a living organizational system.

## User and priority

- Primary user: a team member who does not know Org Brain's internal vocabulary.
- Priority: explanation and next action first; technical metadata remains available as supporting detail.
- Primary CTA: open the relevant Task, Memory, Decision, or Resource.

## Desired impression

A premium organizational instrument panel: near-black depth, glass navigation, precise electric-blue signals, and one meaningful animated focal area per screen.

## Must preserve

- Activity flow topology and path pulses.
- Knowledge graph exploration, selected-node glow, and shape-based semantics.
- Strata lanes, present-time marker, and revision history.
- Existing routes, API contracts, feature flags, scope parameters, empty states, and accessibility fallbacks.

## Must avoid

- Generic KPI-card grids.
- Decorative motion that does not encode state.
- Automatic destructive advice.
- Raw internal terminology as the primary label.
- Color-only meaning or mobile horizontal clipping.
