# Component Contracts

## InsightPageGuide

Renders three short, permanent orientation statements. Semantic list, no client JavaScript, one column below 720px.

## RecommendedActions

Renders deterministic review candidates with severity text, evidence, and a scoped source link. When empty, renders an explicit healthy state. Never recommends deletion or fabricates missing evidence.

## Activity integration

The selected event highlights matching actor and project paths. The topology remains the dominant visual. Attention CTAs select evidence or open its authoritative Task.

## Connection integration

Sparse graphs scale to available width; dense graphs remain bounded and scrollable. Inspector metrics include plain-language interpretation and conservative review candidates.

## History integration

Current content, latest change, evidence count, and review state precede the timeline. User-facing labels are plain language; raw snapshot metadata lives in a native details disclosure.
