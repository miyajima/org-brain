## ローカルの変更

`packages/orgbrain-cli/src/lib/memory-task-consistency.mjs` の `known-fact-consistency/v3` は、特定の出典・資料・項目に値が記載されていないという完結した句を、保持済みの事実全体を否定する文と区別する。対象は設定場所、分母、件数、測定効果。語が含まれるだけの免除にはせず、句全体を一致させる。別の句や文の「対象件数は不明」、全体件数の変更、出典不在から再集計不能へ飛躍した文は引き続き拒否する。

保持引用の出典ID・ハッシュ・引用位置、権限・期限・対象、実操作の入力と出力、保持部分の同一性は維持する。出典限定の実草稿が修正前に拒否されることを再現し、修正後は53件の関連動作テストが成功した。v2の実際の過剰拒否草稿はv3で許可され、v3で観測した全体分母の否定は再生でも拒否される。再生は機能確認でありモデル評価0回。

## 通常利用

既存の `.local/memory-reuse/config.json` は `task_local_mode=on`、`task_confirmation_mode=ask`、`task_delta_consistency=on`、`task_retained_fact_max_chars=1200`。通常起動は `pnpm claude:work research|analysis|document`。`pnpm claude:work list` はモデルを起動せず対象と単位を確認する。今回設定全体を書き直しておらず、既存フック・権限・無関係な変更を保持した。評価DB・成果を通常DBへ移していない。実装や出典が変わった古い成果は指紋不一致となるため、そのまま有効と読み替えない。

原成果が受け入れ済みで、必要な事実と適用条件を満たし、今回の不足単位を限定できる場面に使う。保持引用は原成果の一部であり、引用にない事項を原成果全体で不明と断定しない。作成費を参考配分した比較では、分子に費用が追加されることと、比較の分母が変わることを混同しない。一般的な意味品質は自動検査だけで保証できず、利用者の成果確認が必要。
