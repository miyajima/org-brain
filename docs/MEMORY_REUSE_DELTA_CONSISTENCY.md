# 差分生成へ保持事実を渡し、結合後の整合を検査する

このプロジェクトのローカルClaude CLI用。実装・自動テスト・承認済みの実モデル比較を完了し、通常設定の新フラグを有効化した。品質保持のための採用であり、初回作成費を含むトークン・時間削減は未達。クラウドや共有ハーネスのbootstrapは変更していない。

## 設定と適用範囲

`.local/memory-reuse/config.json` の `task_delta_consistency=on` と `task_retained_fact_max_chars=1200` で有効にする。既存の `task_local_mode`、`task_confirmation_mode`、本文の標準入力、短い完了応答を維持する。開始は `pnpm claude:work research|analysis|document`。

登録した `task_workflows.*.retained_fact_topics` は、調査の測定結果、分析の全体件数・対照値、文書の設定場所を対象とする。現在の資料、Node・実装版、利用者、権限、有効期限、元成果のハッシュが一致している場合だけ、その元成果を使う。

差分を選ぶと、ホストは保持される節から必要な文をそのまま抜き出す。新たな要約モデルは起動しない。引用には元成果のID・ハッシュ、単位、元の文中の開始・終了位置を付ける。上限は引用文の合計文字数であり、ID等のメタデータを含む全パケットの長さとは区別する。文を途中で切らず、必須の事実が収まらなければ `task_retained_facts_incomplete` でモデル起動前に止める。

保持事実は `retained_context` として、現在の差分資料と同じ起動時の文脈に入る。セッション・対象・読取結果・保持事実のダイジェストを照合し、改ざんや別の元成果への置き換えを拒否する。引用は過去の成果の文脈であり、新たな独立検証やモデルの原本読取として数えない。

## 結合後の検査と限界

モデルは追加する節だけを書く。ホストは他の節を変更せず結合する。実行前には、保持節にある設定場所・件数・対照値を不明とする記述、機械・APIの測定済み効果を未検証とする記述、明示的な全体件数の食い違いを検査する。該当すると `task_retained_fact_contradiction` で拒否し、同じ承認範囲の本文を直すよう通知する。全体作業への切り替えを勝手に許可しない。

実操作後にも、実アダプターの出力、完成ファイル、保持部分の一致を確認し、同じ整合検査を行う。検査版・対象項目・結果は完了した成果と `task_completion.consistency_check` に残る。実行前拒否、同じCLI内の修正、CLIの再実行の費用はすべて測定へ含める。

自動検査の対象は上記の既知事実の否定と全体件数であり、あらゆる意味の矛盾を保証しない。人の確認時間、実請求、実チーム利用、一般化など、本当に未観測のものは不明のままにする。モデル評価では別コードの証跡監査と、結合後の全文確認を併用する。

今回、分析の「この出典には分母(n)の記載がない」という差分資料に限った記述も拒否した。同じ草稿には保持済みn=10への参照があったため、保守的な過剰拒否と判断した。モデルは同じCLI内で全体集計を参照する表現へ修正した。この往復を計測から除外していない。出典に記載がないことと、文書全体で事実が不明なことの区別は、次の検査改善に残る。

## 比較と復旧

比較計画は `artifacts/memory-task-coherence-20261031/PROTOCOL.md`。初回成果3件を現在の実装で作り、その作成費を同じ元成果の2回の差分へ配分する。記憶なしは全3単位、改善版は追加1単位を作る。全6件の総計には初回費を一度だけ加える。人の新版実測・旧版実測・推定を分け、欠測を0で埋めない。

`python3 scripts/memory-task-coherence-eval.py prepare` はモデルを起動しない。`seed` と `run` は、承認済みの実行上限・費用が記録されていない限り停止する。`python3 scripts/memory-task-coherence-report.py` は新しいモデルを起動せず、実ログの4区分トークンと実操作を監査する。

無効化は `task_delta_consistency=off`。既存の記憶・操作追跡を外さず、他の設定は保持する。通常設定の変更前バックアップは `.local/memory-reuse/install-backups/` にある。設定全体の復元で、その後の無関係な変更を上書きしない。評価用DBや成果は通常DBへ取り込まない。

## 2026-10-31の比較結果

初回3件、記憶なし6件、改善版差分6件の15回で、累計496回。API換算は全評価1.103213 USD、承認済み2.00 USD・累計499回以内で終了した。失敗・CLI再起動は0、同一CLI内の検査拒否と修正は1回。実モデルはログでclaude-sonnet-5-5、effort mediumを照合した。実請求と実装・監査費は別勘定で未取得。

結合後の全文を親が照合し6/6件で既知事実の保持を確認し、引用・実操作・完成ファイルの独立したコード監査は15/15件が整合した。一般的な意味の正しさや、人による成果の採用を保証するものではない。

各元成果を固定2課題で再利用し、初回作成費を全額一度だけ含めると、記憶なし223,481トークン・141.28秒に対し、改善版231,010トークン・174.47秒だった。トークン+3.37%、機械時間+23.49%、API換算-1.41%。初回費を除いた再利用だけは125,269トークン・108.20秒（トークン-43.95%、機械時間-23.42%）だった。初回費を含めて両方削減できたとは認定しない。

新版の人の確認時間は欠測。旧版の初回確認実測と混ぜず、10/30/60秒の純増人時間は仮定による感度分析として報告する。今回の機械時間はすでに合計33.19秒増えているため、純増人時間が正なら総時間はさらに増える。
