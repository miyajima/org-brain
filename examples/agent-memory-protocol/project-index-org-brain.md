# OrgBrainの作業手順

共通ルールを読んでから今回の手順を選ぶ。実行時の設定と対象を確認し、実行結果は別に記録する。

## Always
- [作業前の共通ルール](amp/projects/org-brain/rules.md): 現行AGENTS.md、ブランチ、既存変更、テスト方針を確認する。

## Procedures
- [ローカルAPIと画面の起動](amp/projects/org-brain/local-start.md): 開発用の画面を確認するとき。
- [Cloudflareへの反映](amp/projects/org-brain/deploy.md): 対象環境への公開を依頼されたとき。準備・公開・公開後の確認を分ける。
- [AMPの実装と検証](amp/projects/org-brain/amp-checks.md): 記憶の形式、検索、プロジェクト索引、ローカルMCPを変更するとき。
